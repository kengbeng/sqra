Semi-Quantitative Risk Assessment

Assess chemical exposure, identify IH monitoring and statutory medical examination (SME) requirements.

How to use this tool
  1. Create an assessment. Enter the activity, department, location and date.
  2. Add chemicals. Search the list and enter the exposure information for each chemical. Use “Chemical not listed? Add manually” for an unlisted chemical.
  3. Check the results. Read the IH monitoring and SME outcomes. Complete draft chemicals and resolve missing SME information.
  4. Save. Select “Save assessment” to keep your changes in the register.
  5. Print. Select “View printable report”, then “Print / Save PDF”.

Remember to save: Adding or updating a chemical does not save the assessment. Select “Save assessment” to keep your changes.

To update a saved assessment, select Open. Use Edit details to change the activity information.

About this assessment

This tool screens chemical exposure to identify IH monitoring and statutory medical examination (SME) requirements. Results depend on the information entered and reference data. It does not measure actual exposure levels.

IH monitoring measures workplace exposure and helps check how well exposure controls work. SME uses hazard-specific medical examinations to detect early signs of occupational disease and assess fitness for the work.

This assessment helps identify follow-up needs. See MOM guidance on hygiene monitoring and medical monitoring.

Saving and backups

Assessments are stored locally in this browser on this device. They are not shared automatically. Clearing browser data may remove them.

  • Export: Use Backup → Export register to download a backup.
  • Import: Use Backup → Import register to restore or transfer records. Imported records with matching IDs replace the existing records.

To move from the local file to the published website, export from the local file and import on the website.

Help choosing exposure ratings

Use information for the activity being assessed. Weekly quantity and duration describe how the chemical is used; the controls rating describes existing controls and maintenance.

The number beside each option is its exposure index. Higher indices increase the calculated exposure rating. Particle size applies to solids; vapour pressure applies to liquids and gases.

“Not available” excludes that factor from the calculation; it does not mean zero exposure. Record the missing information under “Uncertainties or notes”. If required information is missing, use “Save as draft” and complete the chemical later.

Chemical changes are kept only when you save the assessment.

Advanced: use a different reference file

Online, the website loads chemical-reference.json automatically. When opened directly from your computer, it uses the built-in copy unless you import a file.

Import a reference JSON file while in the register. It applies to this session only; reimport after reloading. Importing does not change saved assessments.

How to update reference data

Keep an unchanged backup before editing. Use verified source information. Do not guess missing ratings.

Use a file temporarily

  1. Select Download JSON and save a backup. Edit a copy in a text editor.
  2. Update the relevant chemical entries using the formats below. Change version for each revision, for example 2024-12-27-r2. Change referenceDate only when the underlying reference source changes.
  3. Return to the assessment register. Under Advanced: use a different reference file, select Choose reference JSON and import the edited file.
  4. Check the import message and active version. Use View reference data to check the changed entries, then test the affected assessment results before relying on the file.

Session only: importing does not publish the file or change saved assessments. Reimport after reloading the page. To reassess a saved chemical, select Apply current reference values in its editor, review the result, update the chemical and save the assessment.

Reference JSON field formats
FieldRequired format
schemaVersionKeep as 1.
versionA unique text label for each revision, in double quotes.
referenceDateThe reference source date as "YYYY-MM-DD".
nameA unique chemical name, in double quotes.
hazard, vapourIndex, otPelIndexWhole numbers 1 to 5, or null when unavailable. Do not use zero or put numbers or null in quotes.
medicalExactly "Required", "Not Required", "Not stated" or "Verify".

Keep the chemicals array and valid JSON punctuation, including commas, brackets and double quotes. Source-error markers such as #REF! need checking against the source; do not replace them with an assumed rating.

Update the shared website: maintainers only

  1. Complete the import and result checks above. Keep a backup of the currently published reference file.
  2. Rename the verified file chemical-reference.json. Replace that file in the SQRA GitHub repository and commit the change. Repository write access is required.
  3. Wait for GitHub Pages deployment to succeed. Reload SQRA and check that it uses the website reference file and shows the new version under Advanced. Check the changed entries in the viewer.

Routine reference updates do not require editing index.html. The embedded fallback remains a separate, frozen copy. Published reference changes do not automatically update saved assessments.
